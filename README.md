# 🎮 get_level_of_monkey

2D Action игра с видом сверху на движке **Panda3D** с интеграцией **BrainLink** через Shared Memory!

## 🎯 Особенности

- 🧠 **Управление мыслями** через BrainLink
- ⚡ Система энергии и HP
- 🎭 RPG элементы: диалоги, прокачка
- 🐵 Мини-игра "Обезьянья атака"
- 🎨 Pixel-art графика
- 📊 Интеграция с BrainLink Client через Shared Memory

## 🚀 Установка

```bash
# Создать виртуальное окружение
python -m venv venv

# Активировать (Windows)
venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt
```

## 🎮 Запуск

```bash
python main.py
```

## 🕹️ Управление

### Клавиатура:
- **Стрелки**: Движение (вверх, вниз, влево, вправо)
- **Space**: Взаимодействие/Диалог

### BrainLink (Shared Memory):
- **ml** (Move Left): Влево
- **mr** (Move Right): Вправо
- **mu** (Move Up): Вверх
- **md** (Move Down): Вниз
- **stop**: Остановка

## 👥 Кооп на 2 игрока (LAN)

Два компьютера в одной сети (или два процесса на одном ПК через `127.0.0.1`):

1. **Хост** — главное меню → **«Сетевая игра»** → **«Создать хост»**, порт по умолчанию `17777` (см. `config/game_config.json` → `multiplayer`).
2. Второй игрок — **«Сетевая игра»** → **«Подключиться»**, IP хоста и тот же порт (LAN-адрес хоста показывается в статусе).
3. После подключения игра **автоматически** стартует в пещере для обоих.
4. **Хост** управляет переходами между локациями и симуляцией мини-игры; клиент получает `scene_change` и снимки мини-игры.
5. **Solo** — кнопка «Один» без сети.

**Windows:** разрешите входящие TCP на выбранный порт в брандмауэре на машине хоста.

### Ручной тест-план

| # | Шаг | Ожидание |
|---|-----|----------|
| 1 | Два процесса: Host + Join `127.0.0.1` | Оба в cave, видят второго персонажа при движении |
| 2 | Хост заходит в exit → kitchen | Клиент телепорт в kitchen |
| 3 | Хост → minigame (диалог отца) | Клиент в той же мини-игре, обезьяны/какашки с хоста |
| 4 | Закрыть клиент | Сообщение об отключении, возврат в меню |
| 5 | Solo «Один» | Игра как раньше, без второго спрайта |

Логи: `game.log` (если настроено логирование в файл).

## 🔗 Интеграция с BrainLink

1. Запустите **BrainLink Client** (из директории `$BRAINLINK_CLIENT_DIR$`)
2. Подключите устройство или запустите Simulator
3. Включите **☑ Enable Shared Memory** в UI
4. Запустите игру: `python main.py`
5. Игра автоматически подключится к BrainLink!
6. **Управляйте мыслями!** 🧠

**Проверка подключения:**
```
✅ Connected to BrainLink: 'brainlink_data'  # В логах
❌ BrainLink not found                        # Если не подключен
```
